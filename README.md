# One Word, First Thought

Entry for the make.fun bounty **"One Word, First Thought"**
(`u-0xkianno-one-word-first-thought-106abaf8`): send exactly one word, the
first that comes to mind, and a judge compares words two at a time on which
is more interesting.

## The entry

**skullduggery** — secret scheming and underhanded mischief, plotted in a
back room. It is vivid (a skull, a scheme, a grin), surprising (nobody
expects a word with a skull in it to be the first thought), and fun to say
twice: the sound itself feels like mischief being hatched.

## How it works

`main.py` (Python standard library only) writes the single word to
`/output/entry.txt` — exactly one word, 12 characters, UTF-8, no trailing
newline — then reads the file back and asserts it is byte-identical.
